สถานะฐานข้อมูล Supabase Cloud

ระบบเชื่อมต่อกับ Online Database (Supabase Cloud) เรียบร้อยแล้ว ข้อมูลทั้งหมดได้รับการบันทึกแบบ Real-time

สถานะ: เชื่อมต่อสำเร็จ (Online) ความเร็ว: ~65 ms

จัดการพื้นที่จัดเก็บลายเซ็น (Cloud Storage)

แปลงลายเซ็น Base64 ในฐานข้อมูลขึ้น Supabase Storage (Bucket: signatures) เพื่อลดขนาดฐานข้อมูลลงกว่า 99%

ล้างข้อมูลเพื่อเริ่มเทอมใหม่

การล้างข้อมูลนี้จะลบ **บันทึกเวลาเรียน (att)** ทั้งหมดออก เพื่อให้พร้อมใช้งานสำหรับเทอมใหม่ (ข้อมูลรายชื่อนักเรียน ครู และวันหยุดจะไม่ถูกลบ)
